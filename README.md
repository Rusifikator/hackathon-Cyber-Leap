# Социальные агенты — КИБЕР РЫВОК 2026

Симуляция социальных агентов с диалогами, отношениями и графом связей. Агенты общаются друг с другом, реагируют на сообщения игрока и генерируют реплики и действия с помощью LLM (Focus API). Проект создан для хакатона.

## Возможности

- **Симуляция в реальном времени**: агенты по очереди генерируют реплики и действия ([Жизнь]), обновляют планы и отношения.
- **Лента событий**: диалоги (A → B: реплика), действия [Жизнь] и сообщения игрока в одном потоке.
- **Граф отношений**: визуализация связей между агентами.
- **Чат 1 на 1**: просмотр диалога между выбранной парой агентов.
- **Влияние игрока**: можно вводить фразы от имени игрока — они попадают в ленту и влияют на агентов.
- **Панель управления**: настройка отношений между агентами, создание и редактирование персонажей (имя, пол, личность, настроение, план).
- **Авторизация**: регистрация и вход по логину/паролю (JWT-подобные сессии, PBKDF2-SHA256).

## Запуск

### Бэкенд

1. Перейди в каталог `backend` и создай виртуальное окружение (по желанию):

   ```bash
   cd backend
   python -m venv .venv
   .venv\Scripts\activate   # Windows
   # source .venv/bin/activate  # Linux/macOS
   ```

2. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Скопируй `.env.example` в `.env` и укажи ключ Focus API:

   ```bash
   copy .env.example .env   # Windows
   # cp .env.example .env   # Linux/macOS
   ```

   В `.env` задай:

   ```env
   FOCUS_API_KEY=твой_ключ_focusapi
   ```

4. Запусти сервер:

   ```bash
   uvicorn app:app --reload --host 0.0.0.0 --port 8000
   ```

   API и WebSocket будут доступны на `http://localhost:8000`.

### Фронтенд

Фронт — статические файлы. Можно открыть их любым способом, главное — чтобы запросы шли на бэкенд с порта 8000.

- Открой `frontend/index.html` в браузере (или раздай папку `frontend` любым HTTP-сервером).
- В `auth.js` и `main.js` используется тот же хост, что и у страницы, с портом 8000 — убедись, что при открытии с `file://` в коде указан правильный хост (например `localhost:8000` для API).

## API (кратко)

| Метод / путь        | Описание |
|---------------------|----------|
| `POST /auth/register` | Регистрация (username, password, display_name) |
| `POST /auth/login`    | Вход, в ответе — токен |
| `GET /auth/me`        | Текущий пользователь (заголовок `Authorization: Bearer <token>`) |
| `POST /auth/logout`   | Выход |
| `GET /state`          | Состояние симуляции (агенты, события, граф) |
| `WebSocket /ws`       | Подписка на обновления; отправка текста — сообщение от игрока в ленту |
| `POST /event`         | Добавить событие в ленту (body: `{"text": "..."}`) |
| `GET /history`        | История событий (query: `limit`) |
| `GET /graph`          | Граф отношений |
| `POST /relations`     | Установить уровень отношения между двумя агентами |
| `POST /agents`        | Создать/обновить агента |

## Переменные окружения (backend)

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `FOCUS_API_KEY` | Ключ API focusapi.ru для LLM | — (без ключа LLM отключён) |
| `FOCUS_BASE_URL` | Базовый URL Focus API | `https://focusapi.ru` |
| `FOCUS_MODEL` | Модель | `focus-ai` |
| `LLM_MAX_TOKENS` | Макс. токенов ответа | `512` |
| `SIMULATION_INTERVAL_SECONDS` | Интервал между тиками симуляции (сек) | `1.2` |
| `ACT_DELAY_MIN_SEC`, `ACT_DELAY_MAX_SEC` | Пауза между репликами внутри тика (сек) | `5`, `7` |
| `INTERACTIONS_PER_TICK` | Сколько реплик за один тик (при 2 агентах) | `3` |
| `LIFE_EVENT_PROBABILITY` | Вероятность добавить [Жизнь]-действие после реплики | `0.45` |
| `ENABLE_VECTOR_DB` | Включить векторную БД (Chroma) для памяти | не задано |


## Технологии

- **Backend**: Python, FastAPI, LangGraph (граф состояний reflect → act), WebSocket, NetworkX (граф отношений), LangChain + Focus API (LLM).
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla), шрифт Kreadon.
- **Аутентификация**: сессии по Bearer-токену, пароли хешируются PBKDF2-SHA256.
